# Tidy — Mac 效率整理助手(开源,MIT)

菜单栏 App:**PARA** 管文件与资源流转,**GTD** 管事项闭环。核心理念:
> 把事情处理好,而不是记住所有事。大脑用来产生想法,系统负责存放与调度,人只关注眼前一步。

AI 出草稿、人只确认;**不配 AI 也完全可用**(本地规则 + 拼音模糊搜索 + 记忆检索)。

## 快速开始

```bash
git clone <repo> && cd TidyApp
./setup-signing.sh   # 一次性:创建固定自签名证书(系统授权跨 rebuild 保留;弹钥匙串确认时选「始终允许」)
./build.sh --run     # 编译 → 组装 dist/TidyApp.app → 签名 → 启动
```

- 无需 Xcode,仅 Command Line Tools(macOS 14+,Swift 6)。
- 首次启动自动弹新手指引;首次 ⌥⌘A 会请求「自动化(Finder)」权限。
- **AI 配置(可选)**:菜单栏 → 「AI 设置(.env)…」自动生成模板(见 `docs/env.example`),支持任何 OpenAI 兼容接口;`PARA_ROOT` 可自定义根目录。
- 开机自启:系统设置 → 通用 → 登录项,添加 `dist/TidyApp.app`。
- 无头自测:`.build/debug/TidyApp --smoke`。

所有数据(SQLite、埋点、记忆)只存本地 `~/.tidy/`;仅在配置了 AI 后,分类/理清请求会发往你自己填的接口。

## 日常使用

| 操作 | 方式 |
|---|---|
| 归档文件 | 拖文件到桌面悬浮窗;点按悬浮窗或 `⌥⌘A` 归档 Finder 选中项 |
| 确认面板 | `1/2/3` 立即归档(最快路径:拖入 + 按 1);打字即模糊搜索(支持拼音首字母,`khj` → 客户A支付网关);`⇥` 重命名;`esc` 取消 |
| 新建项目/领域 | 面板里搜索无结果时直接 `↵` 创建,不用跳出 |
| 撤销归档 | `⌥⌘Z`,或点归档后 toast 里的「撤销」 |
| 捕获想法/链接 | `⌥⌘N`,回车保存;聚焦期间自动关联当前项目 |
| 理清收件箱(GTD) | 状态栏菜单或工作台「开始理清」:AI 自动区分想法/任务,预填下一步行动+期望结果+清单路由+优先级+时间提醒;`↵` 确认、`⌘T` 两分钟做完、`⌘⌫` 丢弃、`⌘→` 跳过 |
| 四清单 | 工作台标签页(⌘1-7 切换):收件箱 / 行动 / 等待 / 搁置 / 已完成 / 统计,每页顶部有适用说明;清单页 `↑↓` 选行、`↵` 完成(收件箱=理清),纯键盘操作 |
| 理清快捷键 | `⌥⌘I` 全局唤出理清队列,无需经过菜单 |
| 统计分析 | 工作台「统计」页(⌘7):GTD 漏斗(捕获→理清→完成)、理清率、两分钟规则命中率、清单存量、归档命中率/耗时,全部本地埋点计算 |
| 等待催办 | 等待清单条目显示「已等 N 天」,搁 ≥3 天每日 10 点后提示催办 |
| 项目截止 | 项目详情右上角点徽章弹日历设置/清除截止日期 |
| 项目工作台 | `⌥⌘P`:总览 = GTD 仪表盘(今日完成庆祝 + 收件箱提醒 + 艾森豪威尔矩阵 + 全局下一步行动);打字搜项目进一屏详情 |
| AI 拆解 | 项目详情 →「AI 拆解」:自然计划法(目的→期望结果→头脑风暴→组织计划),步骤可编辑/排序(逻辑/时间),确认后成为行动链——全局列表只露出第 1 步,完成自动解锁下一步 |
| 时间提醒 | 捕获/理清文本里提到「明天下午3点」等时间自动打 ⏰ 标记,到点弹提醒(带「完成」按钮) |
| 定期提醒 | 待办半天一次(09:30/14:30 简报)、收件箱每日、搁置清单每周一、每周五提示复盘;菜单可随时「每周复盘…」 |
| 两分钟规则 | 捕获后 toast 即问「2 分钟能搞定就现在做」;理清面板 AI 判断 ≤2 分钟时橙色横幅提示立即做 |
| 聚焦模式 | 工作台里点「进入聚焦」:25 分钟时间盒,状态栏倒计时,结束记一句进展 |
| 改归档规则 | 状态栏菜单 → 编辑 MEMORY.md,改一行文本即可,启动/开菜单时自动同步 |
| 看命中率 | 状态栏菜单 → 统计(全部本地埋点,不出网) |

## 架构速览

```
Sources/TidyApp/
├─ App/          main + AppDelegate(状态栏/自检/装配) + EnvConfig(~/.tidy/.env) + SmokeTest
├─ Capture/      DropWindow(悬浮窗) HotKeyManager(Carbon,免辅助功能权限)
│                FinderSelection(AppleScript) InputPanel(捕获/聚焦结束共用)
├─ Panel/        ArchivePanel(top-3 确认面板+键盘交互) FuzzyMatcher(拼音) Toast
├─ Workbench/    Workbench(项目工作台) FocusManager(时间盒)
├─ Core/
│  ├─ Database/  GRDB schema(§6 全部表)+ FTS5(memory_ft)
│  ├─ Memory/    MEMORY.md/USER.md ↔ DB 双向同步 + FTS5 检索 + trust scoring
│  ├─ Classifier/ 本地层(词面+记忆+聚焦上下文,毫秒级)→ 云端轻档兜底(json_schema strict)
│  └─ Archiver/  移动 + Finder 标签 + bookmark + ActionLog 撤销
└─ Telemetry/    suggest/confirm/correct/fallbackSearch/undo,本地 SQL 直接算 P0 指标
```

关键设计落点:

- **下限锁死**:面板用本地规则秒开,AI 结果异步到达后才合并;AI 失败只显示一行提示,搜索不受影响。
- **修正即学习**:凡是没选第 1 位的归档,自动落一条 episodic + 种子语义规则(写回 MEMORY.md),记忆背后的规则做 hit/miss 计分。
- **冷启动**:记忆库为空时面板提示「你的选择会成为规则」,选择即种子,无需前置标注。
- **实测网关坑的应对**:启动自检 GET /models 并区分大小写校验模型名;云端返回的路径若不逐字匹配列表(实测会发生),按后缀/包含关系归位而非丢弃。
